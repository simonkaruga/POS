2. Service Description

Faida POS is a cloud-based, offline-first point-of-sale and business management platform designed for Kenyan businesses. The service includes:

  • Point-of-sale transaction processing with KRA eTIMS compliance
  • Inventory management including batch tracking, FEFO, and stock movements
  • Multi-store management with role-based access control
  • M-Pesa Daraja API integration for mobile money payments
  • Paystack card payment processing
  • HR, payroll (Kenya PAYE/SHIF/NSSF), and leave management tools
  • Financial reporting, P&L, and bank reconciliation
  • AI-powered demand forecasting and sales analytics
  • Hospitality mode with table management, KOT routing, and bar tab functionality
  • Offline-first architecture with IndexedDB sync
  • REST API access (subject to plan limits)
  • Native desktop application (Tauri) and mobile applications (iOS/Android)

We reserve the right to modify, enhance, or discontinue features with reasonable notice. Material feature removals will be communicated at least 30 days in advance via email and in-app notification.
